# Product scenarios (example)

Copy to `.pr-review/scenarios.md` in your repo. One `##` section per product area; one-line bullets; no implementation detail.

## Orders
- Create an order from a saved template
- Edit an order while it is in draft status
- **Approve an order** — approver; from the notification email
  - Open the order from the link
  - Approve, then confirm the status changes to approved
  - Reject with a remark and confirm the creator is notified

## Account
- Sign in with SSO, then refresh mid-flow without losing state
